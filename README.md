# Navneet CSC Digital Seva Kendra

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open it in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Build for deployment
Run `npm run build`. Upload the generated `dist` folder to a static hosting provider such as Netlify or Vercel.

## Before publishing
- Confirm the address spelling and phone number.
- Add the real opening hours if desired.
- Only advertise services for which the center has the required authorization. Aadhaar and banking services in particular require relevant authorization.
- The site currently has no online application backend or admin dashboard; WhatsApp and phone contact are active.
